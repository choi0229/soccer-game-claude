# 시즌 기록: 세 판 비교

같은 시드(1)로 한 판씩, 처음부터 끝까지 따라간 기록입니다. 규칙과 수치는 v9 그대로이고, 아래의 이상한 점도 고치지 않고 적기만 했습니다.

|---|---|---|
| [다크호스-균형.md](다크호스-균형.md) | 라온길공고 (다크호스, 전력 40) | 균형 |
| [다크호스-훈련위주.md](다크호스-훈련위주.md) | 라온길공고 (다크호스, 전력 40) | 훈련 위주 |
| [강호-균형.md](강호-균형.md) | 해밀내고 (강호, 전력 60) | 균형 |

- 전략은 시뮬레이터의 전략을 그대로 썼습니다.
  - **균형**: 새벽 운동은 월·수·금만 합니다. 수업 태도는 집중 → 졸기 → 질문 → 친구 순서로 돌립니다. 훈련 메뉴 7종을 날마다 돌리고, 일요일은 휴식 → 감독 → 동료 → 가족(열리면 여자친구까지) 순서로 돌립니다.
  - **훈련 위주**: 새벽은 체력 50 이상이면 개인 운동을 합니다. 수업은 학업 성취 40 미만이면 집중하고 아니면 좁니다. 메뉴는 파워와 제공권을 번갈아 하고, 일요일은 늘 휴식합니다.
  - 이벤트 선택지는 두 전략 모두 무작위입니다. 승부처는 균형이 무작위, 훈련 위주가 성공 확률이 가장 높은 선택지입니다.
- 다시 만들기: `docker compose run --rm simulator --seed 1 --season-log /out/docs/season-log`
  - 시즌 기록과 시뮬레이터가 같은 판을 도는지는 테스트(`seasonLogPlaysTheSameGameAsTheRunnerAndCoversEveryWeek`)로 확인했습니다.
- 시드가 같아도 행동이 다르면 게임 난수를 쓰는 순서가 달라집니다. 그래서 세 판은 첫 주부터 다른 판이 됩니다. 다크호스 두 판도 상대 학교와 대진만 같고 경기 결과는 다릅니다. 한 판씩이라 전략끼리의 차이를 말하기엔 표본이 작습니다. 1,000판 평균은 `simulation-report.md`에 있습니다.

**판별 흐름**
- **다크호스 + 균형**
  - 3주차부터 주전으로 뛰었습니다(22경기 중 선발 21).
  - 주력 능력치는 한 해 동안 +9.9 올라 셋 다 F에서 E가 되었습니다.
  - 관계도는 네 축이 모두 3단계에 닿았고, 35주차에 여자친구 축이 열렸습니다.
- **다크호스 + 훈련 위주**
  - 주력 능력치가 +27.0 올라 슈팅 파워와 헤더는 C까지 갔습니다.
  - 대신 나머지 능력치(+3.2), 관계도, 이벤트가 거의 움직이지 않았습니다.
- **강호 + 균형**
  - 리그 14경기 동안 벤치 또는 교체였고, 첫 선발은 29주차 추계배였습니다.
  - 교체로 나와 8골을 넣어 평균 평점은 세 판 중 가장 높습니다.
  - 학교가 리그 3위를 해서 왕중왕전에 나간 판은 이 판뿐입니다.

## 읽으면서 이상하다고 느낀 점

수치와 규칙은 고치지 않았습니다. 판단은 맡기고, 근거가 된 기록만 붙입니다.

1. **학년 후반 반년 동안 경기가 거의 없습니다.**
   - 7월 4주(20주차)부터 2월 4주(48주차)까지 29주 동안 경기는 추계배가 있는 29~30주차뿐입니다. 강호는 왕중왕전 1경기가 더 있습니다.
   - 9월과 11월~2월은 세 판 모두 경기가 0입니다.
   - 그래서 10월 이후에는 평판이 거의 그대로입니다(다크호스 균형 21 → 24, 훈련 위주 20 고정).
   - 이 기간에는 겨울방학에 오른 능력치를 경기에서 확인할 방법이 없습니다.
2. **경기 관련 이벤트가 경기가 없는 시기에 나옵니다.**
   - 「선발 명단에 오르다」는 조건이 `lastMatchRole: starter` 하나이고 기간 제한이 없습니다. 그래서 마지막 경기(30주차)에서 17주 지난 47주차에도 나옵니다.
   - 「골 세리머니 약속」의 본문은 "다음 경기도 선발이다"인데, 남은 경기가 없는 46·48주차에 나왔습니다.
   - 「후반 교체 투입」도 강호 판에서 마지막 경기 4주 뒤에 나왔습니다.
   - v8에서 다른 경기 이벤트에 붙인 `lastMatchWithinWeeks`가 이 세 이벤트에는 없습니다.
3. **이미 주전인데 '먼저 선발된 동기'가 나옵니다.**
   - 다크호스 + 균형은 22주차에 「먼저 선발된 동기」("같이 입학한 동기가 먼저 선발 명단에 들었다")를 봤습니다.
   - 그 시점에 이미 19경기 중 18경기를 선발로 뛰었습니다. 조건이 `minWeek: 12` 하나뿐이라서입니다.
   - 「선발 명단에 오르다」("선발 명단 맨 위에 네 이름이")가 한 판에 4번 나온 것도 같은 문제입니다(6·18·30·47주차). 본문이 처음 뽑힌 날을 그리고 있습니다.
4. **이벤트 양이 일요일 만남에 크게 좌우됩니다.**
   - 균형 두 판은 만남이 있는 일요일마다 거의 매번 이벤트가 나왔습니다(35번).
   - 일요일 이벤트까지 더하면 이벤트의 4분의 3 이상이 일요일에 생깁니다(81번 중 60번, 73번 중 59번). 일요일 하나에 만남 이벤트와 일요일 이벤트가 같이 나오는 주가 많습니다.
   - 일요일에 늘 쉬는 훈련 위주는 이벤트가 33번으로 절반도 안 됩니다. 8월 4주~9월 4주는 5주 내리 아무 일도 없었습니다.
   - 훈련 위주는 관계도도 일 년 내내 거의 그대로입니다(감독 30 → 40). 감독·동료 인연 1단계는 47주차에야 생겼습니다.
5. **주력 능력치 차이가 경기 기록에 잘 드러나지 않습니다.**
   - 다크호스 두 판의 주력 평균은 63.0과 45.9로 17 넘게 차이 납니다.
   - 그런데 골은 7과 8, 평균 평점은 6.32와 6.19입니다.
   - 한 판이라 표본은 작습니다. 다만 1,000판 평균 평점도 다크호스 훈련 위주 6.14, 균형 6.09로 차이가 작습니다.
6. **강호는 리그 동안 선발이 한 번도 없습니다.**
   - 이 판에서 첫 선발은 29주차(추계배)입니다.
   - 1,000판 표에서도 강호 + 균형은 전반기 선발이 0%이고, 첫 선발 주차 중앙값이 29주입니다.
   - 감독 관계도가 25주차에 3단계가 됐는데도 리그 경기에는 선발로 뽑힌 적이 없습니다. 첫 선발이 리그 이후로 고정되는 구조로 보입니다.
7. **훈련 위주는 학업 경고가 거의 일 년 내내 켜져 있는데 아무 일도 생기지 않습니다.**
   - 학업 성취는 첫 2주에 50에서 39.6으로 떨어진 뒤 일 년 내내 37~41 사이에 머뭅니다.
   - 경고 기준(40)보다 낮지만, 나머지 공부 기준(30)에는 한 번도 닿지 않았습니다.
   - 이것은 전략 규칙("40 미만이면 수업 집중") 때문입니다. 다만 화면 기준으로는 경고가 거의 늘 떠 있으면서 아무 결과가 없는 셈입니다.
8. **체력이 주 단위로 다 회복됩니다.**
   - 일요일 밤을 보낸 뒤 체력은 세 판 모두 거의 매주 92~103입니다(가장 낮은 주도 87).
   - 훈련 위주는 겨울방학 하루 끝 체력이 20~22까지 내려가 부상 위험 구간(30 미만)에 자주 들어갑니다. 그래도 부상은 0, 훈련 제외도 0입니다.
   - 1,000판 평균 부상도 한 해 0.1회입니다. 체력 관리가 한 주를 넘어 쌓이지 않습니다.
9. **인연 단계가 경계에서 오르내리며 알림이 반복됩니다.**
   - 다크호스 + 균형:
     - 감독 인연이 31주차에 2 → 3, 32주차에 3 → 2, 34주차에 다시 2 → 3이 되었습니다.
     - 여자친구 인연은 0 → 1 → 0 → 1(40·43·44주차)로 오르내렸습니다.
   - 강호 + 균형:
     - 동료 인연이 3 → 2 → 3(31·33·35주차)으로 오르내렸습니다.
     - 학교 친구 인연은 9~11주차에 0 → 1 → 0 → 1이 되었습니다.
10. **균형 판은 관계도가 한 해 안에 상한에 닿고, 특성은 어느 판도 2단계에 못 갑니다.**
    - 감독·동료·가족 관계도가 98~100으로 끝나서, 3단계가 된 뒤로는 더 오를 데가 없습니다. 다크호스 균형에서 가족이 3단계가 된 것은 16주차입니다.
    - 반대로 특성 점수는 세 판 모두 9~22에 머물러, 2단계 기준(25)에 닿은 특성이 하나도 없습니다.
